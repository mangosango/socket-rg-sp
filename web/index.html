Converting...socket-baseos.zip

1. Install BaseOS

Download and install BaseOS. Back up TF1 first: flashing erases it. When BaseOS is ready to add a frontend to the SD card, continue to step 2.

2. Install Socket

Extract the contents of socket-baseos.zip to the root of your visible BASEOS SD card volume.

If you have an existing installation, back up System/launch_frontend.sh before overwriting it. Merge folders; do not replace System or delete your games, saves or settings. Another System/frontend takes precedence.

3. Add your games

Copy your own ROMs into Games/GB, Games/GBC or Games/GBA. Eject the card and boot. Choose Scan in each platform’s editor to find your games.
